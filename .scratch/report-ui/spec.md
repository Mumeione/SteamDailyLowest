# 报表 UI 批次（report-ui）spec

> Status: spec 待审
> 决策时间：2026-09-22，需求来自用户六条想法，逐条已确认
> 实现顺序建议：R2 → R4 → R3 → R6 → R1 → R5 → R7（先删后加，纯前端收尾）

## 背景

当前报表（`templates/` + `src/report.py` + `templates/static/app.js|css`）只有折扣降序一种排序，
卡片详情排版松散，链接无图标。用户提出 6 条改进，本文档是定稿。

## 需求（用户确认版）

### R1 排序（组内）

- 维度三选一：**默认 = 折扣降序（现状）** / 价格升 / 好评率降。
- 好评率排序附带「好评数量范围筛选」chips：全部 / ≥500 / ≥5000，
  作用于**当前组**的显示集合；「详情待补」（无 reviews）的条目不参与好评率排序，固定排组尾。
- 排序范围：**只影响当前分组**，不跨组。
- 切换排序或筛选后，该组回到第 1 页。
- payload 需补数值字段 `price_int`（`reviews.score/count` 已在 payload）；
  前端不用 `price_text` 字符串排序。

### R2 删除 ITAD 链接

- 用户实测：`itad_url`（ITAD deal 链接）302 直跳 Steam 商店页，信息冗余 → **删除**。
- 卡片展开态去掉 ITAD 链接（`app.js buildCard` 的第三个链接）。
- `classify.SEEN_KEEP` 去掉 `itad_url`（新落库省 ~348KB/全量）；
  `classify.py` 里「itad_url 348KB 可砍」的旧注释更新为本决策。
- 旧 `state.json` 里已落的 `itad_url` 字段**留存不迁移**（下次该条目更新时自然消失）。

### R3 详情排布

- `card-detail` 中间加**竖向分隔线**，分左右两栏：
  - 左栏 = 价格类：Steam 史低 / 全周期最低 / 近一年最低；
  - 右栏 = 时间 + 比价：折扣开始 / 折扣结束 / 各比价行。
- 窄屏（≤ 断点 768px）回落单栏纵向堆叠。

### R4 链接前置 + SVG 图标

- Steam / 小黑盒链接移到 `card-summary` 的**价格区、折扣价之前**（横向小图标排布）。
- 图标用 **inline SVG 常量**内嵌 `app.js`（不下载 favicon 文件、不发外链请求）；
  链接保留文字 `aria-label`。ITAD 不再有链接（R2）。

### R5 密度切换（一行一条 / 一行两条）

- 页面级控件：**单列 / 双列**。手机端默认单列；PC 端可切双列（每行两张卡）。
- 选择存 `localStorage`，刷新保持。
- 双列时**每页条数不变**（不与断点分页逻辑耦合，避免「布局与每页条数错位」的老坑 §7.3）。

### R6 英文名显示

- payload 里 `title`（ITAD 英文名）已有，**零新增请求**。
- 规则：**PC + 单列** → 卡片标题旁灰色小字英文；
  **手机端 / 双列模式** → 只在详情展开里显示「原名」一行。
- fallback：若联动实现麻烦，全部放详情展开里（用户已许可）。

### R7 方向键翻页

- `←` / `→` 对「当前活动分组」翻页。
- 活动分组 = 最近一次被点击翻页按钮 / 卡片的分组；无记录时 = 第一个未折叠分组。
- 与现有按钮翻页共用 `pages` 状态；输入焦点在输入控件上时不响应（当前页面无输入框，防御性判断即可）。

### R8 封面图换小尺寸

- 现状：卡片缩略图用 `banner600`（回落 `banner400`/`boxart`），但缩略图只有几十像素宽，
  600px 大图加载慢（用户反馈）。
- 改法：`report.py` 的 payload `banner` 字段改为**优先 `boxart`**（ITAD assets 里的小尺寸），
  `banner600/400` 不再使用；`boxart` 缺失时保持现状回落（前端已有无图模式兜底）。

## 验收

- [ ] `python tools/check_payload.py` 通过（分组标签一致性 / 中文名 / 比价覆盖率）。
- [ ] payload 与卡片中**无 `itad_url`**；`SEEN_KEEP` 不再含该字段（单测）。
- [ ] 排序三维度 + 好评数筛选在单组内生效，切换后回第 1 页（单测前端逻辑以手测为准）。
- [ ] 768px 断点两侧：详情两栏/单栏、密度切换、链接图标位置均正确。
- [ ] 英文名按 R6 规则显示。
- [ ] `←`/`→` 翻页与按钮一致。
